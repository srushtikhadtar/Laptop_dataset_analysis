# 💻 Laptop Data Analysis using SQL

### 1. Project Overview

This project analyzes a laptop dataset using **MySQL** to understand laptop brands, prices, specifications, processors, RAM, storage, operating systems, and ratings.

### 2. Business Problem

The objective is to understand the laptop market and identify useful insights such as **popular brands, pricing patterns, specifications, and highly rated laptops** to support better business decisions.

### 3. Dataset

The dataset is collected from **Kaggle** and contains information about different laptops and their specifications.

### 4. Features

* Brand
* Laptop Name
* Price
* Specification Rating
* Processor
* CPU
* RAM
* ROM/Storage
* GPU
* Display Size
* Operating System
* Warranty

### 5. Status Definition

* **Available:** Laptop record is present in the dataset.
* **Price:** Selling price of the laptop.
* **Specification Rating:** Rating representing the laptop's specifications.
* **Brand:** Manufacturer of the laptop.
* **Warranty:** Warranty period provided with the laptop.

### 6. Data Cleaning

* Checked the dataset structure using `DESCRIBE`.
* Checked for missing values.
* Identified unique values in categorical columns.
* Checked incorrect or blank values.
* Standardized data where required.
* Verified price and rating values.

### 7. Exploratory Data Analysis (EDA)

The analysis includes:

* Number of laptops by brand
* Average laptop price
* Minimum and maximum prices
* Laptop distribution by RAM
* Laptop distribution by operating system
* Processor-wise laptop count
* Specification rating analysis
* Price range analysis

### 8. Business Analysis

The project answers questions such as:

* Which brands have the most laptops?
* What is the average laptop price?
* Which brands have higher average prices?
* Which laptops have the highest ratings?
* Which laptops are available in different price ranges?
* Which operating systems and processors are commonly used?

### 9. Key Results

* Identified the **number of laptops available for each brand**.
* Calculated the **average, minimum, and maximum laptop prices**.
* Identified **top-rated laptops**.
* Compared **pricing across different brands**.
* Analyzed laptop distribution based on **RAM, processor, and operating system**.
